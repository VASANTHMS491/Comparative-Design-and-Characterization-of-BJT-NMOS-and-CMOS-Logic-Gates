# Comparative-Design-and-Characterization-of-BJT-NMOS-and-CMOS-Logic-Gates
I was curious about the differences between logic gates built using different transistor technologies, so I thought, “Why not just build them and find out myself?” This repository is a record of what I built, observed, and learned throughout that process.
## Why I Made This

During my semester holidays, I saw a YouTube video, which explained how a computer was made using different transistors, so I thought, let's make some logic gates using transistors, and then remembered there are different transistors like BJT and the MOSFET, and in the MOSFET there are NMOS logic gates and CMOS, so instead of simply making the logic gates, I thought I could compare the differences between the same logic gates built using different building blocks.

I don't have much prior knowledge about this topic, and since I'm curious and completely unaware, I thought, okay, let's simulate the circuits first, then realise it using hardware, and find the difference, with the help of AI. I hope in the end I can understand the difference, instead of just knowing it from the books, or accepting it just because it is written.

## What I'm Doing

I am planning to use LTspice software to simulate the logic gates. Every simulation is done with all the transistors: BJT, NMOS, and CMOS. I will verify the input-output relations before realising them in hardware.

I will calculate the differences between the three in simulation and in hardware, then compare both the results.

I am planning to do NOT, NAND, NOR, AND, OR, XOR logic gates, Half Adders, Full Adders, Latches, and Flip-Flops.
